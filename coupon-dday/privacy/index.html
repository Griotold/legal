2. 앱이 처리하는 정보

쿠폰 이미지와 쿠폰 정보

사용자가 사진 앱에서 선택하거나 카메라로 촬영한 쿠폰 이미지, 브랜드, 상품명, 유효기간, 바코드 또는 QR 코드 값, 등록·수정·사용 완료 시각을 쿠폰 관리와 만료 알림 제공을 위해 처리합니다. 이 정보는 앱 전용 로컬 저장공간에만 보관되며 개발자가 운영하는 서버로 전송되지 않습니다.

사진, 카메라, OCR과 바코드 인식

사진 권한은 사용자가 선택한 쿠폰 이미지를 읽는 데, 카메라 권한은 실물 쿠폰을 촬영하는 데 사용합니다. 이미지의 문자와 바코드 인식은 Google ML Kit를 통해 기기에서 수행합니다. 앱은 인식 대상 이미지나 결과를 개발자 서버에 업로드하지 않습니다. 사용자는 저장 전에 자동 인식 결과를 직접 확인하고 수정할 수 있습니다.

알림과 화면 기능

사용자가 알림을 허용하면 쿠폰 식별값과 상품명을 이용해 유효기간 7일 전, 3일 전과 당일 오전 9시에 로컬 알림을 예약합니다. 알림 예약 정보는 iOS 알림 시스템에서 처리됩니다. 쿠폰 사용 화면은 바코드 인식을 돕기 위해 화면 밝기를 일시적으로 높이고 화면을 닫거나 앱이 비활성화되면 원래 밝기로 복원합니다.

공유와 클립보드

사용자가 공유 또는 복사를 선택한 경우에만 쿠폰 이미지, 상품 정보 또는 바코드 값이 iOS 공유 시트의 선택 대상이나 시스템 클립보드로 전달됩니다. 이후 정보 처리는 사용자가 선택한 앱과 서비스의 정책을 따릅니다.

광고 및 동의 관련 정보

Google Mobile Ads SDK와 User Messaging Platform(UMP)은 광고 제공, 부정 사용 방지, 빈도 관리, 측정, 동의 관리와 진단을 위해 IP 주소를 바탕으로 한 대략적 위치, 기기·앱 식별자, 제품 상호작용, 광고 데이터, 충돌·성능·기타 진단 정보를 처리할 수 있습니다. 실제 항목과 목적은 Google의 SDK, 사용 지역, 동의 선택 및 광고 설정에 따라 달라질 수 있습니다.

앱은 필요한 지역에서 UMP가 제공하는 동의 화면과 광고 개인정보 선택 진입점을 표시하며, UMP가 광고 요청을 허용한 뒤에만 광고를 요청합니다. 동의 확인 실패나 광고 미제공은 쿠폰 관리 기능을 막지 않습니다. 앱은 Apple 앱 추적 투명성(ATT) 권한을 요청하지 않습니다.

쿠폰 이미지와 관련 기록은 사용자가 삭제하거나 앱을 삭제할 때까지 기기의 앱 전용 저장공간에 보관됩니다. 앱은 해당 저장공간을 iCloud 백업 대상에서 제외합니다. 사용자가 쿠폰을 삭제하면 관련 로컬 이미지와 예약 알림도 삭제합니다. 공유한 정보, 클립보드 내용 또는 다른 앱에 저장된 사본은 사용자가 해당 위치에서 직접 관리해야 합니다. Google이 처리하는 광고 관련 정보에는 Google의 보관 및 삭제 정책이 적용됩니다.

5. 제3자 서비스와 국외 처리
