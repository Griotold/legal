자주 묻는 질문

세트 수는 언제 올라가나요?

한 세트를 마친 뒤 30초, 60초, 90초 또는 120초 버튼을 누르면 휴식 타이머가 시작되면서 세트 수가 1 올라갑니다.

다른 휴식 시간을 누르면 어떻게 되나요?

실행 중에도 선택한 시간으로 즉시 새 휴식이 시작되고 다음 세트로 계산됩니다. 단순히 현재 시간을 되감으려면 다시 시작 버튼을 사용하세요.

화면이 자동으로 꺼지지 않아요.

기본 설정에서는 운동 중 확인하기 쉽도록 화면 켜짐을 유지합니다. 설정 → 화면 켜짐 유지에서 끌 수 있습니다.

인터넷이 없어도 사용할 수 있나요?

네. 광고를 제외한 타이머, 세트 카운터, 설정 기능은 오프라인에서도 동작합니다.
